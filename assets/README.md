# سياسة الأصول ومجموعة القبول

لا توضع صور أو كتب عشوائية من الإنترنت في المستودع. كل أصل تجريبي يجب أن يحمل:

- المصدر وصاحب الحق.
- نوع الترخيص.
- هل يسمح بالتعديل وإعادة التوزيع؟
- نوع الاختبار الذي يغطيه.
- النتيجة المتوقعة بصورة أو manifest معتمد.

## البنية

```text
assets/
├── fixtures/
│   ├── images/
│   └── books/
├── expected/
│   ├── layer-documents/
│   └── previews/
└── manifests/
    └── corpus.json
```

## مجموعة القبول المقترحة

- شخصيات بخلفية شفافة ومصمتة ومزدحمة.
- رسم يدوي، كرتوني، واقعي، وملابس/إكسسوارات متداخلة.
- حواف شعر، زجاج، ظلال، أجزاء دقيقة، وأطراف مقصوصة.
- PDF عربي RTL وإنجليزي LTR ومختلط.
- نص مضمّن، صفحات ممسوحة، أعمدة، جداول، حواشٍ، وخطوط غير متاحة.
- ملفات تالفة أو خبيثة مصطنعة داخل مجموعة أمن منفصلة لا تُفتح يدويًا.

يجب استخدام أصول مصنوعة داخليًا أو مرخصة مثل CC0/CC-BY مع الالتزام بنسبة العمل.

## أصول العرض التسويقي

تُحفظ الصور المصدرية الكبيرة في `visual-sources/` خارج `apps/web/public` حتى
لا تُنسخ إلى حزمة الإنتاج. يربط `visual-sources/manifest.json` كل أصل بمخرجه
المحسّن داخل `apps/web/public/visuals`.
