# Support

## Product and development questions

Collaborators may open a GitHub issue using the provided forms for reproducible,
non-sensitive bugs or scoped product proposals. Include the affected version or
commit, environment, expected behavior, actual behavior, and the smallest
redacted reproduction.

This repository does not provide a public service-level agreement. Production
incidents must use the deployment owner's incident channel and the runbooks in
`docs/runbooks/`; a GitHub issue is not an incident-response mechanism.

## Security and privacy

Do not disclose vulnerabilities, credentials, private URLs, customer data,
uploads, exports, or exploit details in an issue or pull request. Follow
[SECURITY.md](SECURITY.md) and use
[GitHub private vulnerability reporting](https://github.com/ahmed1122-rpg/riig-/security/advisories/new).

If a report contains sensitive data accidentally, stop sharing it, revoke or
rotate affected credentials, and contact the deployment security owner.
