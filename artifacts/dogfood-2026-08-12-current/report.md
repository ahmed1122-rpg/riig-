## النتائج

### ISSUE-001 — فقد مسودة مناطق PDF عند مغادرة مساحة العمل

- **الخطورة:** عالية
- **المسار:** مساحة PDF ← إضافة منطقة ← العودة إلى الرئيسية
- **النتيجة المتوقعة:** مطالبة المستخدم بتطبيق المسودة أو تجاهلها، أو حفظها كمسودة محلية.
- **النتيجة الفعلية:** تتم المغادرة فورًا بلا تنبيه وتُفقد المنطقة غير المطبقة.
- **إعادة الإنتاج:** ارفع PDF، أضف منطقة، ولا تضغط «تطبيق وحفظ المناطق»، ثم اضغط «العودة إلى الرئيسية».
- **الأدلة:** [قبل المغادرة](screenshots/issue-004-a-unsaved-region-before-navigation.png)، [بعد المغادرة بلا مطالبة](screenshots/issue-004-b-navigation-without-draft-warning.png).
- **التوصية:** إدخال حالة مسودات الصورة وPDF في حارس التنقل نفسه المستخدم لتعديلات الطبقات، وتغطية العودة وتغيير الوضع واستبدال المصدر و`beforeunload`.

### ISSUE-002 — نموذج الإحداثيات يقبل منطقة بعرض صفري

- **الخطورة:** عالية
- **المسار:** PDF ← إدخال الإحداثيات
- **النتيجة المتوقعة:** رفض أي منطقة لا تحقق `x + width <= 100` و`y + height <= 100` وبُعدًا موجبًا ظاهرًا.
- **النتيجة الفعلية:** يقبل النموذج `x=100` و`width=50`، ثم يقص العرض إلى صفر ويضيف منطقة غير مرئية يمكن إرسالها للحفظ.
- **إعادة الإنتاج:** أدخل `x=100`، واترك العرض `50`، ثم اضغط «إضافة منطقة» و«تطبيق وحفظ المناطق».
- **الدليل:** [لقطة المنطقة الصفرية](screenshots/issue-002-zero-width-region.png).
- **التوصية:** تحقق صريح في العميل والخادم، ورسالة خطأ بجانب الحقل، ومنع الإرسال بدل القص الصامت.

### ISSUE-003 — تجميع طبقات صفحتين تحت عنوان «الصفحة 001»

- **الخطورة:** متوسطة
- **المسار:** PDF متعدد الصفحات ← الصفحة الثانية ← رصيف الطبقات
- **النتيجة المتوقعة:** عرض طبقات الصفحة الحالية أو تجميعها تحت عناوين الصفحات الصحيحة.
- **النتيجة الفعلية:** تظهر طبقات الصفحتين وخلفيتاهما تحت عنوان ثابت «الصفحة 001» أثناء عرض الصفحة الثانية.
- **الدليل:** [لقطة التجميع الخاطئ](screenshots/issue-001-layer-page-grouping.png).
- **التوصية:** تجميع فعلي حسب `pageNumber`، مع قسم الصفحة الحالية مفتوحًا وثابتًا وإبقاء بحث «كل الصفحات» اختياريًا.

### ISSUE-004 — سبب تعطيل أدوات سطح المكتب غير متاح بوضوح

- **الخطورة:** متوسطة
- **المسار:** شريط أدوات PDF على سطح المكتب
- **النتيجة المتوقعة:** أن يشرح الزر المعطّل سبب عدم توفر الأداة بصريًا وللتقنيات المساعدة.
- **النتيجة الفعلية:** اسم الزر المساعد هو «إعادة OCR للمنطقة» فقط؛ السبب موجود في `title` على زر HTML معطّل، وهو نمط غير موثوق للمس ولوحة المفاتيح وقارئات الشاشة.
- **الدليل:** [لقطة الأداة المعطلة بلا سبب ظاهر](screenshots/issue-003-disabled-tool-no-visible-reason.png).
- **التوصية:** استخدام `aria-disabled` مع منع التنفيذ وإضافة نص مرتبط عبر `aria-describedby`، كما هو مطبق بالفعل في لوحة الهاتف.

### ISSUE-005 — قائمة طبقات الهاتف ترسم كل الصفحات بلا نافذة عرض

- **الخطورة:** متوسطة (ترتفع إلى عالية مع PDF كبير)
- **المسار:** عرض الهاتف ← لوحة الطبقات
- **النتيجة المتوقعة:** قائمة افتراضية/مجزأة مرتبطة بالصفحة الحالية، مع بحث للوصول إلى بقية الصفحات.
- **النتيجة الفعلية:** تعرض اللوحة كل طبقات كل الصفحات دفعة واحدة. الملف الصغير يعرض 8 صفوف، بينما الحد الخادمي يسمح حتى 100,000 عنصر نصي.
- **الدليل:** [لقطة قائمة الهاتف لكل الصفحات](screenshots/mobile-layers-all-pages.png).
- **التوصية:** إعادة استخدام نافذة العرض أو virtualization على سطح المكتب والهاتف، وبحد أقصى ثابت لعُقد DOM المرئية.

## مسار نجح

نجح التسجيل، إنشاء المشروع، رفع PDF ثنائي الصفحات، المعالجة، التنقل بين الصفحتين، اختيار طبقة من صفحة أخرى مع مطالبة تجاهل المسودة، والعودة بعد إلغاء/تأكيد المطالبة. لم تسجل وحدة التحكم أخطاء JavaScript في المسار المستقر.

## قيد الدليل

تعذر تسجيل فيديو إعادة الإنتاج لأن `ffmpeg` غير مثبت في بيئة العمل؛ لذلك حُفظت لقطات قبل/بعد للعيب السلوكي. الاختبار شُغل على خادم API ثابت بدل وضع `tsx watch` لأن مخزن التطوير داخل الذاكرة يُفقد الجلسة عند إعادة تشغيل عملية API.
