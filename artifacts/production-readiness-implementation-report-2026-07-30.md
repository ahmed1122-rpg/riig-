# تقرير تنفيذ الجاهزية الشامل

**آخر تحديث:** 2026-07-31  
**القرار الحالي:** الأدوات مكتملة محليًا؛ **No-Go للإنتاج** حتى إغلاق بوابة OCR والأدلة التشغيلية الخارجية.

## الخلاصة التنفيذية

أُغلقت فجوات الأدوات الست التي كشفها التدقيق السابق، وأصبحت لها عقود خادم وحفظ ذري ومعالجة تعارضات وسجل مراجعات وواجهات فعلية واختبارات:

1. استعادة إصدار مصدر سابق مع سجل actor/reason/from/to وprecondition وidempotency.
2. OCR لمنطقة PDF من المصدر الأصلي عبر عامل المستندات.
3. فصل وحدة نص PDF مع حفظ النص والهندسة وترتيب القراءة.
4. دمج وحدات نص PDF مع قيود الصفحة والمجموعة والاتجاه.
5. تحسين حواف Raster إلى أصل مشتق غير هدّام.
6. دمج طبقات Raster مع حفظ النسخ في سجل المراجعات.

أضيفت مراجعات `layer_document_revisions` الدائمة، وundo/redo عبر الخادم، وCAS، واحتفاظ محكوم يحمي المراجعات المرتبطة بالخط الزمني. كما أضيف مفتاح التعطيل `PDF_REGION_OCR_ENABLED`، وتدخل عمليات OCR الإقليمية في مقاييس HTTP والعامل الحالية دون تسجيل النص.

## دورة OCR المحايدة v6

نُقل مصدرا v5 المفتوحان إلى development. ثم ثُبّت مصدران جديدان بالكامل في holdout v6:

- مطبوع مصري سنة 1927: خمس صفحات.
- مخطوط عربي تاريخي: خمس صفحات.

كل مصدر مثبت برقم صفحة Commons وبصمة SHA-1 وحالة Public Domain، وكل نص مرجعي مثبت برقم صفحة ومراجعة وتاريخ ومستوى تصحيح في ويكي مصدر. بُني corpus من 91 صفحة و20 كتابًا و136 بُعدًا موثقًا.

قبل فتح v6، قيس selector على development/validation فقط. أضيفت قاعدة محدودة للطبعات العربية منخفضة الفصل، تعتمد على خصائص مرصودة لا على معرف العينة:

- 120–199 كلمة.
- ثقة من 0.40 إلى أقل من 0.50.
- نسبة محارف عربية لا تقل عن 0.93.
- تغطية محتوى من 0.35 إلى 0.50.
- المعالجة: `threshold-190` مع `single-column`.

حسّنت هذه القاعدة صفحتي v5 من 58.82% و52.97% إلى 17.94% و13.41%، ولم تطابق أي عينة validation ولم تُضعف نتيجتها.

بعد نجاح `quality` وE2E، فُتح v6 مرة واحدة:

- وقت الفتح: `2026-07-31T11:59:59.287Z`.
- بصمة التنفيذ: `5255fe821215181b7bb75144fa1c9a194835a5519db9bd1d4e525a0c138db3a7`.
- بصمة محتوى holdout: `c53efecd26164b3e5f4b4df301e7180b626ae2f000780924e4d23da22aca71e0`.

| النطاق | الصفحات | CER | النتيجة |
|---|---:|---:|---|
| development | 74 | 18.90% | تشخيصي |
| validation | 7 | 15.13% | مستقر |
| holdout v6 | 10 | 27.02% | فشل؛ الحد ≤25% |
| الإجمالي | 91 | 19.39% | يمر إجماليًا |

تفصيل holdout مهم لاتخاذ قرار المنتج:

- المطبوع 1927: ‏16.26%، وجميع الصفحات تحت حد 50%.
- المخطوط: ‏43.81%، وصفحة `jurjani-008-manuscript` عند 53.76%.
- صفحة الجدول التاريخي في development بقيت عند 69.02%.
- كل صفحات المخطوط الخمس وصفحة الجدول انتهت بثقة أقل من 0.35، ولذلك تُعلّم `needs_review` ولا تمر كنتيجة موثوقة صامتة.

## اختبار محرك بديل

أُجري اختبار جدوى معزول لـPaddleOCR.js 0.4.2 ونموذج `arabic_PP-OCRv5_mobile_rec` داخل Chromium/WASM، من دون إضافته لتبعيات التطبيق. نجح التكامل تقنيًا، لكنه كان أسوأ على صفحة الجدول:

- Tesseract الحالي: ‏69.02% CER.
- PaddleOCR بعد تصحيح اتجاه المحارف: ‏73.36%.
- إعداد الدقة الأعلى: ‏81.43% و11.72 ثانية.

لذلك لم تُضف الحزمة أو النماذج إلى المنتج، ونُظفت كل ملفات الاختبار المعزول. هذا حافظ على وزن الحزمة وحدود الخصوصية ومنع إدخال تبعية تجريبية بلا مكسب.

## الأدلة المحلية النهائية

- `npm run quality`: ناجح بعد آخر تغيير محمي.
- اختبارات معالجة المستندات: 38/38؛ اختبارات الويب: 62/62؛ جميع حدود التغطية ناجحة.
- Playwright E2E: ‏4/4.
- بناء جميع workspaces ناجح؛ ميزانية الويب 131.2KiB JavaScript و36.0KiB CSS مضغوطين.
- `npm audit`: صفر ثغرات معروفة عبر 495 تبعية.
- تحقق fixture بعد فتح v6: 91 عينة، 20 كتابًا، 136 بُعدًا، والبصمات متطابقة.
- مسح TODO/FIXME/HACK/NotImplemented التنفيذي: صفر نتائج.
- اختبار الهجرات المتزامنة وإعادة التشغيل idempotent: ناجح بعد migrations 021/022.
- PostgreSQL/S3 integration الحقيقي: ‏8/8 ناجحة.
- `npm run test:topology:full`: ناجح على نسختي API وRedis وMailpit وMinIO وثلاثة workers وإعادة التشغيل والتصدير وwebhook موقّع.
- أُصلح تعليق Docker على مسار Windows العربي بوصلة junction مؤقتة آمنة ينشئها السكربت وينظفها تلقائيًا.
- صورة الويب اجتازت smoke بنظام ملفات read-only ومستخدم nginx و`cap-drop ALL` و`no-new-privileges`.

## الأدلة الخارجية غير المتاحة

1. لا يوجد remote محمي أو جلسة GitHub موثقة، لذلك لا يمكن تشغيل CI المستضاف أو GHCR بعد.
2. لا توجد هوية مزود أو Bucket فعلي لإثبات S3 encryption/versioning/retention.
3. لا توجد صور إصدار موقعة بالـdigest أو تجربة staging/rollback.
4. لا يوجد تمرين استعادة فعلي موقّع لإثبات RPO≤15 دقيقة وRTO≤4 ساعات.
5. لا يوجد استحقاق Adobe فعّال للتحقق من Golden PSD/After Effects.

## قرار الإصدار

- **Go** للتطوير المحلي والمراجعة الداخلية المقيدة، ووظائف التحرير الست.
- **Go مشروط** لوصف OCR بأنه مساعد محلي للمطبوعات العربية، مع مراجعة بشرية إلزامية للثقة المنخفضة.
- **No-Go** للإنتاج العام أو ادعاء نسخ المخطوطات والجداول التاريخية المتدهورة آليًا.
- أي تغيير جديد في ملفات OCR المحمية يبدأ بجيل holdout v7 جديد؛ لا يجوز تعديل v6 المفتوح أو العتبات لتجميل النتيجة.
