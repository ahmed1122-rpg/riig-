# MotionPrep Studio — واجهة تجهيز الأصول

واجهة React وTypeScript عربية لصُنّاع المحتوى، متصلة افتراضيًا بخدمة MotionPrep
على المنفذ `4000`. يختصر المنتج الرحلة إلى:

`ملف واحد ← اختيار طريقة التجهيز ← معالجة تلقائية ← مراجعة سريعة ← تصدير لأدوبي`

## التشغيل

من جذر المستودع:

```bash
npm install
npm run dev:web
```

أو من هذا المجلد:

```bash
npm run dev
```

## التحقق

```bash
npm run typecheck
npm run build
```

ومن جذر المستودع شغّل بوابة المنتج كاملة:

```bash
npm run quality
```

## قواعد العرض الحالي

- يُرفع ملف واحد فقط لكل مشروع وعملية معالجة، بحد أقصى 30 MB.
- مسار الصور يقبل PNG وJPEG وWebP وAVIF وTIFF وBMP، ومسار الكتب يقبل PDF.
- التسجيل وتسجيل الدخول والرفع والمعالجة والحفظ والتصدير تستخدم API حقيقية؛
  لا تعتمد الواجهة على بيانات العرض بعد رفع مصدر.
- الصور والشخصيات والأشكال والحيوانات محدودة بـ15 طبقة.
- يبدأ كل اسم طبقة بعلامة `+` واحدة.
- ملء الفراغات غير هدّام وله ثلاثة أوضاع: تلقائي، مراجعة قبل التطبيق، إيقاف.
- مسار PDF يوفر فصل: العناوين، الموضوعات، الجمل، الأسطر، الكلمات أو الحروف.
- لكل صفحة PDF خلفية بيضاء ثابتة ومقفلة باسم `+page_001_background`.
- الاسم المختصر يظهر في شجرة الطبقات، بينما يُحفظ النص الكامل في البيانات الوصفية.
- وضعا الكلمات والحروف قد ينتجان طبقات كثيرة؛ توصي الواجهة بملف PSD مستقل لكل صفحة.

## بوابات الإصدار الخارجية

- مصدّر PSD فعلي ومختبر بنيويًا، لكن اعتماد التوافق التسويقي النهائي ينتظر
  فتح ملفات Golden داخل Photoshop وAfter Effects المرخصين.
- OCR العربي يعمل محليًا على عينة Smoke حتمية؛ قياس الدقة على مجموعة كتب
  ممثلة ومصرح بها يظل بوابة قبل التسويق على نطاق واسع.
- الدفع الحي لا يُفعّل قبل توفير حساب Stripe وWebhook موقّع؛ الوضع المعطل
  أو التجريبي هو الافتراضي الآمن.
